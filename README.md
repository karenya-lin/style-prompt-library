# 風格提示詞庫 Style Prompt Library

UI/UX 設計用的視覺風格與 AI 生圖提示詞庫：每種風格附色票、字體搭配、關鍵元素、範例圖（或 CSS/SVG 示意），以及可直接複製的英文 prompt / negative prompt。

## 使用方式

- 直接開 `index.html`，或透過 GitHub Pages 瀏覽。
- 上方類別 chip（全部 / AI 生圖插畫 / 版面風格 / 裝置展示 / 節慶）與搜尋框可依名稱、標籤篩選。
- 點色票複製 hex；點「複製 Prompt」「複製 Negative」複製提示詞。
- 頁尾「Don'ts 學到的教訓」整理了實作時踩過的坑。

## 收錄風格

AI 生圖插畫：3D Clay Christmas、European 2D Animation、Ligne Claire、Risograph、Gouache Picture Book

版面風格：Pop Art Comic、Swiss Style、Esports Character Select、Memphis Milano × Figma Flat、Alpine Christmas + French Folk Ribbon、Photo + Brand Veil + 3D Cards、Dark Neon Cube Field Hero

裝置展示：Frosted Glass Phone on Architectural Plinths

## 備註

- 範例圖皆為 AI 生成，卡面留白、不含任何商標。
- 參考他人作品記錄的風格只寫特徵與提示詞，示意圖用 SVG 自己畫，原圖不放進 repo。
- 單一檔案、無建置步驟；字體來自 Google Fonts。
